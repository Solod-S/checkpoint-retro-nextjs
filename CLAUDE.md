# Claude Code project instructions

Главные инструкции находятся в `AGENTS.md`.

Перед работой:
- прочитай `AGENTS.md`;
- определи текущую фазу по `docs/ai/WORKFLOW.md`;
- загрузи только релевантные `docs/pages/*.md`;
- при UI-задачах обязательно прочитай `docs/design/**`.

Не менять архитектуру или дизайн «для упрощения».

Особенно:
- не читать `.env`;
- не выполнять destructive DB operations;
- не использовать VK / YouTube;
- не создавать произвольные дизайн-значения;
- после изменений запускать проверки, соответствующие задаче.
