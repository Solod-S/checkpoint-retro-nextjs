# Checkpoint Retro — AI Development Blueprint

Этот каталог — источник истины для разработки Checkpoint Retro с помощью локального AI-агента.

## Что здесь есть
- продуктовая идея и границы проекта;
- архитектура Next.js + PostgreSQL + Prisma;
- собственная админка;
- мультиязычность RU / UK / EN;
- SEO-архитектура;
- дизайн-система по предоставленным макетам;
- правила работы AI-агента;
- описание страниц и компонентов;
- чек-листы QA, security и visual QA;
- исходные visual references;
- стартовый промт.

## Как использовать
1. Прочитать `START_HERE.md`.
2. Передать агенту `START_PROMPT.md`.
3. Разрешить агенту читать `AGENTS.md`, `docs/**` и `design/reference/**`.
4. Разрабатывать по фазам из `docs/ai/WORKFLOW.md`.
5. Не разрешать агенту пересобирать архитектуру «с нуля», пока текущая фаза не завершена.

Каталог `../STARTER` содержит минимальный технический skeleton.
