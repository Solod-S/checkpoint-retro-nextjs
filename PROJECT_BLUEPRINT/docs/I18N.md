# Internationalization

## Locales
- ru
- uk
- en

Locale является частью публичного URL.

## Слои
### UI translations
Dictionaries/messages.

### Editorial translations
`PostTranslation`, taxonomy translation models и page translation models.

## Slugs
Slug локализуется:
```text
/ru/articles/istoriya-dreamcast
/uk/articles/istoriia-dreamcast
/en/articles/history-of-dreamcast
```

## Fallback
Не показывать автоматически editorial text другой locale под видом перевода.

MVP: не публиковать locale URL, если перевода нет.

## Dates
`Intl.DateTimeFormat(locale)`.

## Layout resilience
Тестировать длинные RU/UK строки и короткий EN. Не фиксировать ширину кнопок под конкретную строку.
