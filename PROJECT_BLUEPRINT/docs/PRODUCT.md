# Product

## Концепция
Checkpoint Retro — независимое мультиязычное медиа о классических видеоиграх, консолях, технологиях, людях и историях, сформировавших игровую индустрию.

Сайт использует современную информационную архитектуру и UX, а ретро-эстетику — как визуальный язык.

## Основные задачи пользователя
- узнать свежие новости ретро-индустрии;
- читать длинные истории;
- находить материалы по платформе / игре / теме / эпохе;
- искать по архиву;
- переходить между связанными материалами;
- читать на RU, UK или EN;
- делиться материалом.

## Типы контента
### NEWS
Новостной материал.

### ARTICLE
Редакционный материал: история разработки, технология, анализ, подборка.

### STORY
Большой longread / история.

В UI ARTICLE и STORY объединяются в «Статьи и истории».

## Homepage slots
Управляются из админки:
- hero story;
- urgent/breaking strip;
- latest news;
- article/story selection;
- optional editor picks;
- newsletter CTA.

## Контентные принципы
- изображение поддерживает материал, но не заменяет заголовок;
- metadata короткая и стабильная;
- карточки не зависят от фиксированной длины русского текста;
- локализация не ломает layout;
- все блоки работают с реальным CMS-контентом.

## Нефункциональные цели
- SEO first;
- быстрый server rendering;
- Core Web Vitals;
- базовая доступность WCAG AA;
- редактируемость без разработчика;
- предсказуемая работа AI-агентов;
- возможность развивать проект без переписывания фундамента.
