# Visual Implementation Workflow

## Перед страницей
1. прочитать design system;
2. открыть page spec;
3. посмотреть reference;
4. определить reusable components;
5. составить breakpoint plan.

## Реализация
Сначала:
- layout;
- spacing;
- typography;
- imagery;
- responsive behavior.

Потом:
- scanlines;
- corner decorations;
- micro-interactions.

Нельзя начинать с декоративных эффектов.

## Fixture content
На ранних фазах допустимы fixtures, но fixture content не должен попадать в production logic.

## Screenshot QA
Проверить desktop, tablet и mobile.

Сравнивать hierarchy, proportions и density.

## Known reference exception
VK/YouTube icons из старых reference не переносить.
Production: X, Facebook, Threads, Instagram.
