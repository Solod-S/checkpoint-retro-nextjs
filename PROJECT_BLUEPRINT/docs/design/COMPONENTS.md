# Components

## RetroFrame
Panel/card frame:
- thin border;
- optional corner brackets;
- surface background;
- no heavy shadow.

## CornerBrackets
Декоративный элемент, не влияющий на layout и не перекрывающий text.

## RetroButton
Variants:
- primary orange;
- secondary outline;
- active lime;
- icon.

States:
hover, focus-visible, disabled, loading.

## PlatformBadge
Короткая metadata label. Цвет привязан к taxonomy token, contrast обязателен.

## HeroStory
- category/kicker;
- H1;
- excerpt;
- CTA;
- metadata;
- image.

Никакого hardcoded article.

## ContentCard
Variants:
- grid;
- compact;
- horizontal;
- featured.

## BreakingStrip
label + headline/link + optional date.
Без бесконечного marquee по умолчанию.

## ArticleMeta
date + reading time + author + optional update date.

## FilterTabs
Поддерживают overflow на mobile.

## SearchField
Desktop — крупный terminal-like field.
Mobile — компактная версия без потери controls.

## Timeline
Desktop horizontal, mobile vertical.

## NewsletterBanner
CTA без агрессивного popup.

## SocialLinks
Только X/Twitter, Facebook, Threads, Instagram.
