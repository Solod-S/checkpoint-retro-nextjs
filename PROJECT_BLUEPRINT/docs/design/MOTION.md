# Motion

## Motion language
Короткие, механические, четкие переходы.

Подходят:
- border/color transition;
- 1–2px translate;
- quick reveal;
- nav underline.

Не подходят:
- bounce;
- rubber;
- большие spring panels;
- длительный glitch;
- постоянный flicker.

## Reduced motion
Отключать non-essential animation при `prefers-reduced-motion: reduce`.

## Route transitions
Для MVP тяжелые page transitions не нужны.

## Hover
Card hover не должен сдвигать соседние элементы.
