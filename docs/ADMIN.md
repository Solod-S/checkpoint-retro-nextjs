# Admin

## Цель
Редактор управляет сайтом без изменения кода.

## Dashboard
Показывать:
- drafts;
- scheduled;
- последние публикации;
- ошибки scheduled publishing;
- контент без перевода;
- контент без SEO description;
- missing alt / broken media;
- быстрые действия.

- updated;
- filters.

## Translation workflow
Один language-independent Post + отдельные translations.

UI показывает RU / UK / EN, status каждой версии и missing fields.

## Homepage manager
Управляет hero, breaking, latest, stories, editor picks.
Допустим временной диапазон placement.
