# Responsive

## Principle
Mobile — отдельная редакционная композиция, а не уменьшенный desktop.

## Breakpoint intent
Ориентиры:
- mobile: < 640;
- tablet/small desktop: 640–1024;
- desktop: > 1024;
- wide: > 1440.

Финальные media queries определяются содержимым.

## Desktop
- 12-column grid;
- hero 2/3 + supporting region;
- sidebar допустим;
- nav полностью раскрыта;
- cards 3–4 колонки.

## Tablet
- 8-column;
- compact header;
- hero stacked/condensed;
- sidebar sections вниз;
- 2-column grids.

## Mobile
- single content stack;
- hamburger nav;
- horizontal filter chips;
- hero image над текстом или image-card;
- article TOC collapsible;
- supporting sidebars как inline blocks;
- cards чаще list-style.

## Touch
Touch target около 44px.

## Text
Не уменьшать body text ради «влезания». Headline — natural wrap + responsive size.
