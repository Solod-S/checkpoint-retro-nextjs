# Visual QA

Для каждого экрана проверить desktop / tablet / mobile.

## Global
- [ ] header соответствует visual language;
- [ ] logo readable;
- [ ] active navigation lime;
- [ ] CTA orange;
- [ ] background не чисто #000;
- [ ] borders заметны;
- [ ] text contrast достаточный;
- [ ] effects не мешают чтению.

## Grid
- [ ] одинаковые gutters;
- [ ] sections align;
- [ ] cards используют общие ratios;
- [ ] нет случайных widths;
- [ ] tablet не пережатый desktop.

## Typography
- [ ] H1 имеет editorial weight;
- [ ] metadata не конкурирует с body;
- [ ] RU/UK строки не ломают header;
- [ ] line-height body комфортный.

## Mobile
- [ ] no horizontal page overflow;
- [ ] filters scroll внутри;
- [ ] menu reachable;
- [ ] cards без микротекста;
- [ ] article images в viewport;
- [ ] timeline/sidebars перестроены.

## Reference exception
VK/YouTube из старых макетов не переносить.
